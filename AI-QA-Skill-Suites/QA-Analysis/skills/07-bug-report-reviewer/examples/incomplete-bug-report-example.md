# Incomplete Bug Report Example

## Input

Title:

User cannot upload document.

Steps:

1. Upload a document.

Actual Result:

Upload fails.

---

## Expected Review

Status:

NEEDS IMPROVEMENT or BLOCKED

The Skill should identify missing information such as:

- supported document format;
- relevant test data;
- preconditions;
- exact reproduction steps;
- expected result;
- actual error behavior;
- environment information if relevant;
- evidence if available.

The Skill must not invent:

- PDF as the required format;
- maximum file size;
- upload button name;
- error message;
- expected upload behavior;
- technical root cause.

---

## Clarification Questions

Examples:

1. Which document and format were used?
2. What should happen when the upload succeeds?
3. What exactly happens when the upload fails?
4. Is the issue reproducible every time?
5. In which environment does the issue occur?
