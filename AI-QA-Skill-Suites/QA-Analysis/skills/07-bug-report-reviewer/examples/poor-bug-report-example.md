# Poor Bug Report Example

## Input

Bug ID:

BUG-001

Title:

Login doesn't work.

Steps:

1. Try login.
2. It fails.

Expected:

It should work.

Actual:

It doesn't work.

---

## Expected Review

Status:

NEEDS IMPROVEMENT

Issues:

### Title

The title is too vague.

### Reproducibility

The steps are insufficient to reproduce the problem.

### Test Data

No information is provided about the credentials or relevant account state.

### Expected Result

The expected behavior is vague.

### Actual Result

The actual behavior is vague.

### Environment

No environment information is provided.

---

## Important Rule

Do not invent:

- credentials;
- browser;
- operating system;
- error message;
- expected redirect;
- technical root cause.
